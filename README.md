# Plovdiv Waffle Tour 🧇

A multi-page, interactive web project built for the Hack Club Waffles YSWS (You Ship, We Ship) challenge. This project combines the historical charm of Plovdiv (Bulgaria's City of Seven Hills) with a fun, lightweight waffle theme!

##  Features
- **Multi-page Navigation:** Built with separate `index.html` and `tour.html` pages connected via clean styling.
- **Waffle Clicker Counter:** An interactive JavaScript counter on the home page to track your snack energy.
- **Plovdiv Vibe Check:** A dynamic randomizer tool on the tour page that evaluates your local "Maina" spirit.
- **Custom Styling:** Designed from scratch using a warm, custom `style.css` layout.

##  Built With
- **HTML5** (Structural layout and content)
- **CSS3** (Visual themes, cards, and responsive design)
- **JavaScript (ES6)** (DOM manipulation, event listeners, and dynamic interactions)
